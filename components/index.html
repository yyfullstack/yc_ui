平台能力

让组件库从样式集合演进成统一设计语言、统一演示结构和统一测试心智的平台。

主题与 Token

颜色层、阴影层、透明层和状态层统一收口，便于品牌换肤和明暗主题扩展。

状态一致性

hover、focus、disabled、selected 和 loading 在核心组件之间保持统一节奏，降低认知切换成本。

工作台式测试

复杂组件提供稳定的总入口和子场景拆分，更适合做平台级联调、验收和回归测试。

按需接入

既保留单组件 CSS 文件，也提供完整入口文件，兼容传统页面集成和渐进式接入。

快速使用

平台首页负责发现组件，demo 页负责验证交互，CSS 文件负责项目接入。

<link rel="stylesheet" href="./styles/index.css">

<button class="yc-button yc-button--primary">
  主要按钮
</button>

建议的调用方式

首页用于发现组件，demo 工作台用于验证状态和交互，样式入口用于正式接入项目代码。

  • 复杂组件优先提供 workbench 入口，再拆分子场景测试页。
  • 保持 demo 页标题、CSS 路径、工作台入口与实际样式文件一一对应。
  • 新增颜色或透明层语义时，优先进入 variables.css，而不是写死在页面里。
