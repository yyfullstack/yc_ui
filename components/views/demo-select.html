平台建议

推荐做法： Select 在平台层最好统一成“输入框外观 + 下拉层内容 + 清空/箭头操作位 + 选中图标语义”四件套。这样无论是表单字段、顶部筛选器还是工作台切换器，都能沿用相同的视觉和交互心智。
